## Selected Work

**Security & Infrastructure**
- **IP Log Pull & Analysis** — Scripted utility to extract, parse, and analyze IP log data from network and system sources. Automated detection of anomalous traffic patterns with structured reporting; applied to live log files to surface unauthorized access attempts and map activity timelines. *(Python · Log Parsing · Linux CLI · SIEM)*
- **Cisco Packet Tracer — Enterprise Topology** — Multi-device network designed and simulated across segmented VLANs with static and dynamic routing (RIP/OSPF), DHCP, DNS, and ACL-based access control. Validated end-to-end with ping and traceroute; documented with full IP addressing scheme and device roles. *(Packet Tracer · VLAN · OSPF/RIP · ACL)*
- **VMware Linux Environment** — Full Linux build inside VMware Workstation: disk partitioning, network adapter configuration, post-install hardening. Used as a development and security testing sandbox running Wireshark, Nmap, and custom Python tooling. Setup documented for reproducibility. *(VMware · Linux · Wireshark · Nmap)*

**Development & Data**
- **Analytic Data Tracker** — Web scraper and analytics tool that collects, processes, and visualizes structured data from external sources, surfacing trends through a dashboard interface. *(Java · Python · Web Scraping · Data Visualization)*

**Hardware**
- **iPhone LCD Repair** — Screen replacements across multiple models: display assembly disconnection, OEM and aftermarket panel installation, touch response and True Tone verification. Multiple client devices, zero data loss.
- **MacBook LCD & Fan Repair** — Panel and cooling fan replacement on MacBook Pro and Air units, including thermal paste reapplication and post-repair GPU thermal validation.
- **Custom PC Builds & Component Replacement** — Full builds from component selection through cable routing and airflow optimization, plus targeted upgrades (GPU, RAM, SSD migration, PSU). Benchmarked and stress-tested for stability.

**Creative & Commercial**
- **Small Business Brand Design** — Logos, social assets, flyers, and marketing collateral for small business clients.
- **Video & Film Production** — End-to-end production: scripting, editing, motion graphics, final export. Promotional, client, and personal work.
- **eBay Collector Listings** — Sourcing, photography, competitive pricing, and SEO-written listings for collectible electronics and vinyl. Consistent seller rating through accurate grading and reliable fulfillment.
