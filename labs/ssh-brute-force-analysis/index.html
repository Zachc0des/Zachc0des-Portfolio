lab environment: Kali (attacker) → Ubuntu (target)

SSH brute-force log analysis

Export auth.log from the Ubuntu target, find the failed SSH attempts, isolate the Kali IP, and confirm the pattern with SQL.

1. Collect the log on Ubuntu

Go to the log folder

auth.log is a file inside /var/log, so move into the folder first.

cd /var/log
ls -l auth.log

Export the file

sudo cat /var/log/auth.log > ~/auth_export.log
The > redirect runs as your normal user, not sudo. Write the export to your home folder (~/) so it doesn't fail with "permission denied" inside /var/log.

Spot the failed attempts

grep "Failed password" ~/auth_export.log | head -20

Each line carries a timestamp, the username tried, the source IP, and the port.

Get the Kali IP

On the Kali machine, run this and note the address on the lab network.

ip -4 addr show | grep inet

The IP that dominates the failed-password lines should match it. That match confirms your simulated brute force.

2. Parse timestamp + IP with SQL (SQLite)

Load the log into a table

sudo apt install -y sqlite3
sqlite3 auth.db
.mode tabs
CREATE TABLE raw(line TEXT);
.import auth_export.log raw

Create a view of failed SSH logins

Ubuntu 24.04 writes ISO timestamps (2026-11-03T10:15:22…). On older releases the timestamp is Nov 3 10:15:22, so change the first substr to substr(line,1,15).

CREATE VIEW failed_ssh AS
SELECT ts,
       substr(rest, 1, instr(rest, ' ') - 1) AS src_ip,
       replace(usr, 'invalid user ', '')     AS username
FROM (
  SELECT substr(line, 1, instr(line, ' ') - 1) AS ts,
         substr(line, instr(line, ' from ') + 6) AS rest,
         substr(line, instr(line, 'for ') + 4,
                instr(line, ' from ') - instr(line, 'for ') - 4) AS usr
  FROM raw
  WHERE line LIKE '%sshd%Failed password%'
);

Timestamps and IP addresses

SELECT ts, src_ip, username FROM failed_ssh ORDER BY ts;

Which IP is the attacker?

SELECT src_ip,
       COUNT(*)  AS attempts,
       MIN(ts)   AS first_seen,
       MAX(ts)   AS last_seen
FROM failed_ssh
GROUP BY src_ip
ORDER BY attempts DESC;

Confirm it is your Kali box

Replace 192.168.56.101 with the Kali IP.

SELECT ts, src_ip, username
FROM failed_ssh
WHERE src_ip = '192.168.56.101'
ORDER BY ts;

Show the brute-force burst rate

Dozens of attempts in the same minute is the signature of an automated tool.

SELECT substr(ts, 1, 16) AS minute, src_ip, COUNT(*) AS attempts
FROM failed_ssh
GROUP BY minute, src_ip
ORDER BY attempts DESC;

Check whether it succeeded

SELECT line FROM raw
WHERE line LIKE '%Accepted%'
  AND line LIKE '%192.168.56.101%';
